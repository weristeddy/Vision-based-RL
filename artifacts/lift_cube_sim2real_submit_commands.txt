Sim2Real Lift-Cube retrain -- one submit command per architecture
=================================================================

Twelve blocks, one per registered architecture. Eleven are still to run; the
twelfth (DinoV2ViTS14-SpatialSoftmax) is ALREADY SUBMITTED and its command is
commented out so pasting the whole file cannot start it a second time.

Each job is the retained real-texture run of the same architecture, retrained
under the corrected wrist camera and nothing else:

  wrist camera robot/cam, fovy 54.49 (the D405's measured 224-crop vertical
  FOV, replacing the 87 that was its *horizontal* FOV), geom groups (0, 2) --
  the visual meshes, not the collision proxies the retained runs rendered --
  at 224x224, with the D405 housing, window, lenses and optics moved to group
  1 so the imager no longer looks at the inside of its own body.

The hyperparameters below are NOT the rl_cfg defaults. Each of the twelve
retained runs came out of its own Bayesian sweep (configs/sweeps/), so every
architecture has different values -- the learning rate alone spans 6.5x across
the set. Each block's numbers are reproduced verbatim from the W&B config of
the retained run named in its comment, which is what leaves the camera as the
only difference. Passing one architecture's numbers to another would confound
the comparison.

--profile b200 supplies four GPUs and pins --env.scene.num-envs 1024 per rank,
which matches all twelve retained runs and the first sim2real run, so the
topology needs no flag here.

max_iterations comes from rl_cfg and is 6000. RSL-RL counts it from wherever it
starts, so it is iterations *this job* runs, not a total -- a resume would add
another 6000. Append --agent.max-iterations N to override.

Run these from the repo root on the cluster login node. They are independent;
submit them in any order, or only the ones you want.

------------------------------------------------------------------------------
# NatureCnn-LocalGrid16
# hyperparameters from retained run b57mpbee

bash cluster/submit.sh --profile b200 -- \
  Mjlab-LiftCube-Sim2Real-NatureCnn-LocalGrid16-TrossenRealistic \
  --agent.algorithm.learning-rate 0.0003273867414867961 \
  --agent.algorithm.schedule adaptive \
  --agent.algorithm.desired-kl 0.01 \
  --agent.algorithm.entropy-coef 0.005 \
  --agent.algorithm.num-learning-epochs 4 \
  --agent.algorithm.num-mini-batches 8 \
  --agent.algorithm.max-grad-norm 1 \
  --agent.algorithm.gradient-accumulation-steps 8
